# ⚡️ Freelance Orders Interceptor (Бот-перехватчик заказов)

Асинхронный Telegram-бот на Python, созданный для автоматизации поиска заказов на фрилансе. Бот 24/7 мониторит ленты популярных фриланс-платформ и отправляет push-уведомления о новых проектах прямо в Telegram, позволяя откликаться на заказы в первые секунды после их публикации.

Инструмент решает главную боль фрилансеров — необходимость вручную обновлять страницы бирж и проигрывать конкуренцию из-за задержек стандартных RSS-лент.

### 🚀 Основной функционал
* **Мульти-парсинг:** Поддержка 4 платформ (FL.ru, Freelancehunt [API v2], Freelancer.com, Mercor).
* **Разделение доступа (Free/Premium):** 
  * Бесплатный тариф с задержкой отправки и лимитом на ручной поиск.
  * Premium-доступ с моментальными уведомлениями.
* **Встроенная монетизация:** Автоматическая выдача Premium после оплаты через внутреннюю валюту Telegram Stars (`XTR`) или шлюз CryptoBot (`USDT`).
